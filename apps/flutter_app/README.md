# trustkeyper

TrustKeyper Flutter application for brokers, owners, tenants, and administrators.

This is the supported Android, iOS and web client. See the repository-root
`README.md` for Flutter/Firebase setup, isolated UI Test launch, verification
and signed releases. The backend/access rules live at the root. Current product
acceptance is in the root's `docs/handoff-status.md` and
`docs/product-requirements-coverage.md`.
