# TrustKeyper demo rental agreement — demo-v1

DEMO ONLY — NOT FOR SIGNING. This template supports software testing. It is
not a legally approved agreement and must not enter the signing pipeline.

The in-app preview fills the following sections from the validated private
draft, never from sample contacts or guessed amounts:

1. Property address.
2. Every owner: name, mobile and optional email.
3. Every tenant: name, mobile, optional email, rent and deposit shares.
4. Monthly rent, maintenance and security deposit, in numbers and words.
5. Inclusive start/end dates and the selected rent due day.
6. Lock-in and notice periods in months.
7. Separate owner/tenant brokerage and total brokerage.
8. Additional legal conditions: not approved.
9. Signatures, consent, stamp duty and payment: not requested or recorded.

Captured fields are yellow; fields changed since the opened draft are green.
The preview is an immutable snapshot of the validated entered terms. It does
not send a document, save unsaved changes, create participant consent, mark
an agreement signed, or authorize money movement. Copying requires an explicit
confirmation because the text contains entered contact details.

A real release requires an approved legal template, jurisdiction/execution
review and server-owned version/consent/signing evidence. A demo template is
not permission to enable those production transitions.
